 ## Команда для копирования репозитория
 ----------------------------------------
 ```
git clone https://github.com/F4licks/Granich_Beauty
```

## Теперь я чтобы не писать дофига команд для устаноквки тонны космитических библиотек поставил uv
---------------------------------------------------------------------------------------------------

```
pip install uv
```
---------------------------------
Команды для запуска(прописывать в папке с manage.py)
```
uv run manage.py runserver
```
